### 血量无限是怎么做到对所有敌人都通用的

玩家的受伤**只有一个入口**：`hurt(伤害量, 来源x)`。我核对了它的全部 20 处调用，覆盖：

- 近战横扫（小兵 / 锤子 / 狗 / 企鹅扑击）
- 自爆兵爆炸、法师冰霜与法阵
- 敌人子弹命中
- **全部 4 个 Boss 的招式**（冲锋 / 回旋盾 / 斩击 / 震地 / 断头台 / 法阵 / 王冠 / 日蚀）

所以把 `hurt()` 卡死，就等于对所有敌人、所有招式、所有模式（含无尽）同时生效。

```js
// 原版
const i=this.hero, n=e*(1-Math.min(.2,this.config.reduction))*(...)*(...);
return i.hp=Math.max(0,i.hp-n), ...
i.hp<=0&&( ... this.phase="defeat" ... )

// 破解版
const i=this.hero, n=0;              // 伤害不落地
return i.hp=i.maxHp, ...             // 每帧回满
!1&&i.hp<=0&&( ... )                 // 死亡分支永久短路
```

`hero.hp` 的其余写入（大笑回血、黄桃罐头、清箱子、过波、补给站回满）本来都是回血，没有第二条扣血路径。
